# Exploratory Data Analysis: COVID-19 in India

A data-analysis notebook exploring COVID-19 statistics across Indian states and union territories.

## Notebook
The analysis is in [Explonatory_data_analysis.ipynb](Explonatory_data_analysis.ipynb). The notebook loads a CSV dataset and explores its shape, columns, data types, descriptive statistics, state/UT counts, and visualisations.

## Dataset
The notebook expects a CSV file named `Latest Covid-19 India Status.csv`. The dataset is not included in this repository; place it at the path used by the notebook.

## Getting started
1. Clone this repository.
2. Install Python 3, Jupyter, pandas, Matplotlib, Seaborn, and any other libraries imported in the notebook.
3. Place the CSV file in the expected location.
4. Run the notebook cells in order.

## Notes
This is exploratory analysis of a dataset snapshot, not a live COVID-19 dashboard.
